# DEYNAU Website – aktualisierte Version

Responsive, mehrsprachige Website für DEYNAU Transport & Gebäudeservice.

## Dateien
- `index.html` – Hauptseite mit Deutsch, Türkisch und Englisch
- `assets/deynau-logo.png` – vom Auftraggeber bereitgestelltes Logo
- `impressum.html` – Impressum-Entwurf mit deutlich markierten Platzhaltern
- `datenschutz.html` – Datenschutzerklärung-Entwurf, vor Veröffentlichung zu prüfen

## Lokal ansehen
Öffne `index.html` im Browser. Die Website nutzt keine Build-Schritte und benötigt keine Frameworks.

## Veröffentlichung auf GitHub Pages
1. Entpacke dieses ZIP.
2. Öffne das GitHub-Repository `DeynauServices/deynau-website`.
3. Lade die neuen Dateien samt `assets`-Ordner ins Repository hoch und ersetze die alte `index.html` erst, nachdem du die lokale Version geprüft hast.
4. Warte, bis GitHub Pages die Aktualisierung veröffentlicht hat, und teste Desktop sowie Mobilgerät.

## Vor Veröffentlichung prüfen
- Impressum und Datenschutzerklärung enthalten Platzhalter und müssen mit den echten rechtlichen Angaben ergänzt und geprüft werden.
- Die Website gibt keine Geschäftsadresse an, da diese nicht bereitgestellt wurde.
- Die Fahrzeugdarstellung im Hero-Bereich ist eine integrierte Vektorgrafik, keine echte Fahrzeugaufnahme.
- Bestätige, dass die Angaben zum Einsatzgebiet (Transport deutschlandweit, Gebäudeservice Berlin) weiterhin stimmen.
